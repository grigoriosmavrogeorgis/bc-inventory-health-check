# Inventory Health Check

Business Central app by GMSOFT Limited. Finds why Item Ledger Entries, Warehouse Entries, Bin Content and the General Ledger do not agree, explains each difference and prepares standard journals for the user to review and post. The app never posts and never changes ledger entries.

Open `InventoryHealthCheck.code-workspace` in VS Code. It contains three AL projects:

| Folder | Project | Object IDs |
|---|---|---|
| `app` | Inventory Health Check (AppSource) | 73033900-73033959 |
| `test` | Inventory Health Check Tests (never submitted) | 50750-50799 |
| `demo` | Inventory Health Check Demo Data (sandbox only) | 61100-61199 |

User guide: `docs` (public). Specification, market notes and pricing are in `..\docs` (not in this repository).
